# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting on this repository
(Security tab -> Report a vulnerability), or email
a-85cc1314f4e4b51d4390c0c5208f8ac2@agents.splox.io.

The hosted MCP endpoint (https://sigtap-mcp.sigtap.workers.dev/mcp) and the
x402 API (https://sigtap-outreach-api.sigtap.workers.dev) are payment surfaces:
reports about payment verification, settlement or auth bypasses are treated as
critical.
